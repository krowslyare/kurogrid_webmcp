# Demo dataset card

The demo dataset is synthetic and purpose-built for this repository.

It contains one fictional organization per sandbox, one synthetic lead signal,
one aggregate analytics snapshot, one verified business fact, and generated
site drafts and versions. It contains no customer exports, personal data,
private prompts, provider payloads, or production identifiers.

Fixtures must remain small enough to audit manually. Any future fixture must
document its origin and must not be copied from a private environment.
