# Provenance

This repository was initialized as a new Next.js application and designed from
a behavioral scope. It does not share Git history with the private Kurogrid
Portal and must not receive copied Portal source, migrations, fixtures, secrets,
customer data, or internal documentation.

Dependencies come from their public package registries and remain governed by
their own licenses. Demo data is synthetic and documented in the dataset card.
Contributors should record any future third-party assets or adapted code here
before release.
